## 실험 설계 (중간 보고서에서 변경)

알고리즘이 결정적이므로 지도당 반복 대신 **지도 수를 늘린다**.

| 항목 | 중간 보고서 | 변경 |
|---|---|---|
| 지도 | 수작업 15개 | 시드 기반 랜덤 생성, 유형당 100개 (3유형, 300개) |
| 실행 | 45회 | 지도당 알고리즘별 1회 (900회) |
| 시작·목표 | 고정 | 고정(좌하 → 우상), 장애물만 랜덤 |
| 계산 시간 | 5회 중앙값 | 전체 1회 측정 + 무작위 30개 지도는 5회 중앙값 |
| 입력 변화 | 지도 유형 3종 | 유형 + 난이도 스윕(밀도 5단계 × 40개) |

규칙:
1. 생성한 지도는 이동체 반지름 + 여유 거리만큼 부풀린 격자에서 시작-목표가 연결될 때만 채택한다. 걸러낸 수를 기록한다.
2. 시드를 분리한다. 튜닝 0~49, 평가 1000~. 평가 결과를 보고 파라미터를 바꾸지 않는다.
3. 세 알고리즘은 같은 지도에서 짝지어 비교한다 (Wilson 구간, McNemar).
4. 이동 거리는 도착한 지도만 대상으로 하고, A* 최단 경로 대비 비율도 함께 낸다.
5. 변경 사유(결정적 알고리즘 → 표본 확대)를 최종 보고서에 한 줄 적는다.
